# 01 - 项目概览

## 1. 项目定位

**PushGithub**（应用名同工程名，包名 `com.jack.pushgithub`）是一款面向 Android 的"源码仓库同步工具"类应用。它的核心能力是把**本地源码目录**推送到**远程 Git 仓库**，解决移动端"把手机/平板上的项目文件同步到 GitHub/GitLab/Gitee"的需求。

它本质上是一个**轻量级 Git 客户端**，围绕"推送"这个主流程扩展出一整套配套功能。

## 2. 功能清单

| 功能 | 说明 | 入口代码 |
| --- | --- | --- |
| 推送源码到仓库 | 将本地文件夹推送到指定仓库分支，自动处理增删改与 .gitignore | `MainViewModel.startPush()` → `GitHelper.pushSourceToRepo()` |
| 下载仓库源码 | 将远程仓库克隆到指定本地路径（带进度回调） | `MainViewModel.startDownload()` → `GitHelper.cloneDownload()` |
| 快速清空仓库 | 通过 GitHub Git Tree API 一步清空仓库内容（保留 .gitkeep） | `GithubApi.clearRepositoryFast()` |
| 选择文件删除 | 列出仓库文件，勾选后逐文件调用 Contents API 删除 | `GithubApi.getRepositoryFiles()` / `deleteFiles()` |
| 查看提交历史 | 拉取仓库最近提交列表 | `GithubApi.getCommitHistory()` |
| 定时推送 | 通过 WorkManager 周期性自动推送 | `ScheduledPushWorker` |
| 推送历史 | 本地记录每次推送结果（成功/失败） | `PushHistoryDao` |
| 多仓库配置 | 保存常用仓库地址，一键切换 | `RepoConfigDao` |
| 文件预览 | 推送前扫描本地目录文件清单 | `previewFilesBeforePush()` |
| Git 凭据管理 | 加密保存邮箱/用户名/Token | `ConfigRepository`（EncryptedSharedPreferences） |

## 3. 平台支持

- 通过 `GitPlatform` 抽象支持三种 Git 平台：**GitHub**、**GitLab**、**Gitee**。
- 平台检测基于仓库 URL 是否包含 `github.com` / `gitlab.com` / `gitee.com`，默认按 GitHub 处理。
- 克隆 URL 构造逻辑按平台差异化处理（`.git` 后缀补齐等）。

> 注意：`GithubApi`（GitHub REST API 封装）目前**只针对 GitHub** 实现；GitLab/Gitee 的 API 级操作（清空/删除/提交历史）并未实现，仅 JGit 推送/克隆流程通用。

## 6. 运行环境约束

- **minSdk 26**（Android 8.0），**targetSdk 34**，**compileSdk 35**。
- 需要 **所有文件访问权限**（`MANAGE_EXTERNAL_STORAGE`，Android 11+）以直接读写本地路径。
- 需要网络权限；`network_security_config.xml` 禁止明文流量（仅 HTTPS）。
- 使用 `POST_NOTIFICATIONS`（Android 13+ 通知权限）与 `RECEIVE_BOOT_COMPLETED` 权限（为定时推送预留）。
