## 5. ProGuard 规则要点（`app/proguard-rules.pro`）

Release 开启混淆，规则覆盖：

- **Room**：`-keepnames class * extends androidx.room.RoomDatabase`；`-dontwarn androidx.room.**`
- **WorkManager**：`-keep class androidx.work.**`；Worker / WorkerFactory 保活
- **OkHttp / Okio**：`-dontwarn`；保留核心 public 类（`OkHttpClient`、`Request`、`Response`、`Headers`、`MediaType`、`RequestBody`、`ResponseBody`、`Call`）
- **JGit**：`-dontwarn org.eclipse.jgit.**`；保留 `Git`、`UsernamePasswordCredentialsProvider`、`RemoteRefUpdate`（含 `$Status`）、`ProgressMonitor`、`ResetCommand`（含 `$ResetType`）
- **JSON**：`-keep class org.json.**`
- **JGit SSH / Tink 依赖不可用类**：`-dontwarn org.slf4j.**`、`org.apache.sshd.**`、`org.bouncycastle.**`、`javax.management.**`、`javax.security.auth.login.**`、`com.google.errorprone.annotations.**`
- 兜底：`-ignorewarnings`，避免缺失类导致构建失败

> ⚠️ JGit 在 Android 上的 R8 配置是常见痛点，本仓库通过 `-dontwarn` + 选择性 `-keep` + `-ignorewarnings` 的组合保证 release 包可构建。改动 JGit 使用方式时需同步核对 keep 规则。

## 6. 版本兼容性备注

- Compose 编译器 1.5.8 对应 Kotlin 1.9.22（官方兼容矩阵）。
- `security-crypto 1.1.0-alpha06` 为 alpha 版本，API 较稳定但需留意后续迁移。
- AGP 8.2.2 + Gradle 8.5 组合可正常构建（CI 亦使用此组合）。
