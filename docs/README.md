# PushGithub Code Wiki

> 本文档是 Android 项目 **PushGithub** 的结构化技术文档（Code Wiki），用于快速理解项目全貌、定位代码、以及上手开发。

## 项目一句话简介

**PushGithub** 是一款 Android 应用，用于将本地源码文件夹通过 JGit 推送到远程 Git 仓库（GitHub / GitLab / Gitee），并支持仓库源码下载、仓库清空、定时推送、推送历史等配套能力。
