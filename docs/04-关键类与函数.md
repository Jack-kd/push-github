## 3. Git 服务层

### 3.1 `GitHelper`（`git/GitHelper.kt`）

`object GitHelper`，JGit 封装核心。

| 成员 | 签名 | 说明 |
| --- | --- | --- |
| `pushSourceToRepo` | `suspend fun pushSourceToRepo(context, config: GitConfig, repoUrl, sourcePath, sourceUri: Uri?, branch="main", onProgress:(String)->Unit, onFileProgress:(Int,Int)->Unit): Result<String>` | 推源码主流程 |
| `cloneDownload` | `suspend fun cloneDownload(repoUrl, destPath, onProgress:(String)->Unit, onProgressPercent:(Int)->Unit): Result<String>` | 克隆下载 |
| `configureRepoForPush` | `private fun configureRepoForPush(repo: Repository)` | 配置 pack/http 参数（内存与稳定性优化） |
| `loadIgnoreRules` | `private fun loadIgnoreRules(sourceDir: File): IgnoreRules` | 读取默认 + 用户 .gitignore 规则 |
| `compilePattern` | `private fun compilePattern(raw: String): IgnorePattern` | gitignore 通配符 → 正则 |
| `shouldIgnore` | `private fun shouldIgnore(file, sourceDir, rules): Boolean` | 判断是否忽略 |
| `countFiles` / `copyDirectory` | 私有 | 按规则统计/复制并回报进度 |

**`pushSourceToRepo` 内部流程（重点）**：
1. 平台检测并构建克隆 URL（`GitPlatform.detect` / `buildCloneUrl`）。
2. 删除旧临时目录 `filesDir/temp_git_upload`，浅克隆（`depth=1`）；空仓库（无分支）回退 `Git.init` + `remoteAdd(origin)`。
3. 关闭克隆连接，重新 `Git.open`，`configureRepoForPush`。
4. 清空工作目录（保留 `.git`），按 ignore 规则复制源文件（SAF Uri 或本地路径两种来源）。
5. `git.add().addFilepattern(".")` + `status()` 检测变更，无变更直接返回 `"文件无变化，无需推送"`。
6. `commit`（作者用配置用户名/邮箱，消息为"自动更新于 <时间>"）。
7. `push`（`RefSpec("HEAD:refs/heads/$branch")`，timeout 600s）；HTTP 500 时重试最多 3 次（退避 attempt×3s）。
8. 解析 `RemoteRefUpdate.Status`：`OK`/`UP_TO_DATE` 成功，`REJECTED_NONFASTFORWARD` 报错"远程有新的提交"。
9. 清理临时目录，返回 `Result<String>`。

## 4. GitHub API 层

### 4.1 `GithubApi`（`github/GithubApi.kt`）

`class GithubApi(private val token: String)`，OkHttp 封装。

| 成员 | 签名 | 说明 |
| --- | --- | --- |
| `getDefaultBranch` | `suspend fun getDefaultBranch(owner, repo): String` | 仓库默认分支，失败回退 `main` |
| `getCommitHistory` | `suspend fun getCommitHistory(owner, repo, branch, count=20): List<CommitInfo>` | 提交历史（`/commits?sha=&per_page=`） |
| `getRepositoryFiles(repo)` | `suspend fun getRepositoryFiles(repo: String): List<FileInfo>` | 顶层文件树（`/git/trees/<branch>`） |
| `getRepositoryFiles(owner, repo, onProgress)` | `suspend fun getRepositoryFiles(owner, repo, onProgress): List<FileInfo>` | 递归文件树（`?recursive=1`） |
| `clearRepositoryFast` | `suspend fun clearRepositoryFast(owner, repo, onProgress, onProgressPercent)` | 快速清空（Tree API） |
| `deleteFiles` | `suspend fun deleteFiles(owner, repo, files, onProgress, onProgressPercent)` | 逐文件删除 |

**`clearRepositoryFast` 内部 5 步**：
1. `getDefaultBranch` → 获取默认分支。
2. `GET /git/refs/heads/<branch>` 取最新 commit SHA。
3. `POST /git/blobs` 创建空 blob（`content=""`）。
4. `POST /git/trees` 创建仅含 `.gitkeep` 的树。
5. `POST /git/commits` 创建"清空仓库"提交（父为最新 commit）。
6. `PATCH /git/refs/heads/<branch>` 更新分支引用（`force=false`）。

| --- | --- |
| `CommitInfo` | `sha`, `message`, `author`, `date` |

## 9. UI 层（Compose）

### 9.1 `MainScreen`（`ui/MainScreen.kt`）

```kotlin
@Composable
fun MainScreen(viewModel: MainViewModel, onRequestStoragePermission: () -> Unit)
```

- 订阅 `uiState`，网络状态监听（`LaunchedEffect` + `observeNetworkState`），SAF 文件夹选择器 `OpenDocumentTree`。
- 根据状态弹出对应对话框（权限/配置/下载/预览/提交历史/推送历史/定时/清空/文件选择/源码目录）。
- 私有对话框 Composable：`FilePreviewDialog`、`CommitHistoryDialog`、`HistoryDialog`、`ScheduleDialog`、`DownloadDialog`、`SourceDirDialog`、`ClearOptionsDialog`、`FileSelectorDialog`。

### 9.2 `ConfigDialog`（`ui/ConfigDialog.kt`）

```kotlin
@Composable
fun ConfigDialog(
    title: String,
    negativeText: String,
    onNegative: () -> Unit,
    onPositive: (email: String, username: String, token: String) -> Unit,
    initialEmail: String = "",
    initialUsername: String = "",
    initialToken: String = ""
)
```

- 邮箱/用户名/Token 输入 + 密码掩码 + Token 获取帮助 + `GithubVerify.verify` 在线校验，成功后回调 `onPositive`。

### 9.3 主题（`ui/theme/`）

- `PushGithubTheme(darkTheme = isSystemInDarkTheme(), content)`：深浅色 M3 主题 + 系统栏同步。
- `Color.kt`：`PrimaryBlue(0xFF2196F3)`、`PrimaryBlueDark`、`DarkBackground(0xFF121212)`、`SurfaceDark(0xFF1E1E1E)`、`OnPrimary` 等。
- `Type.kt`：`Typography`（titleLarge/bodyLarge/labelMedium 定制）。
